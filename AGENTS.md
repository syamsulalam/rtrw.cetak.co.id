# Agent System Instructions

## Codebase Context and Documentation Rules
- You MUST update `/docs/CODEBASE.md` whenever you add a new file, modify an existing file's core logic, or change how files connect to one another.
- You MUST update `/docs/PRD.md` to reflect the progress on implementation (Implemented, Partially Implemented, Not Yet Implemented) after accomplishing requested tasks or building out new UI screens.
- Read `/docs/CODEBASE.md` and `/docs/PRD.md` to gain context when continuing work in this codebase.

## Focus and Communication Rules
- Focus on completing all tasks specified in `/docs/PRD.md` fully before consulting or reporting to the user.
- Only report or consult with the user when all tasks are complete, if you require specific authorization, or when you encounter a critical blocker/question.
